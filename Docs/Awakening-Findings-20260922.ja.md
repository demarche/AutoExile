# Awakening Boss Rush 改善ループ 気づきメモ（2026-09-22）

改善ループはこの時点で一旦停止。拾得基準 `awakening.minStackChaos = 10`（ユーザー指示）。必須品（Maven's Chisel / Crescent Splinter / Writ 等）は金額に関係なく拾う。

## 本日入れた修正（すべて git コミット済み）
- マーケット検索条件: 1項目ずつ「入力→"Map Tier"ラベルをクリックして確定→InputText/Text で検証」。フォーカス中のフィールドは確定するまで Text が更新されない。
- 拾い漏れ: 同じマップに再入場すると、プッシュ型の EntityCache には地面アイテムが 2〜8 個しか載っていなかった（実際は約 350 個）。EntityListWrapper を毎回スキャンしてキャッシュとマージする。高額品（必須品または 5c 以上）は拾うまで同じインスタンス内で記憶し、再入場後も回収に戻る。
- 読めない地面アイテムでは停止せず、10 秒でスキップ。
- スタッシュ内マップの IIQ は Stats コンポーネントからは 0 と読まれる。Mod の `map_item_drop_quantity_+%` の合計がマーケット表示の IIQ と一致する（116 = 16+19+13+19+10+13+16+10）。これが直るまで、ストックが使われずに毎回マーケットで買っていた。
- MAP タブの T16 表示はページ 1〜6（各 72 枠）あり、順に走査する。ページボタンは VisibleStash の child(3).child(0) の下、テキストは child(0).child(1)。
- 素材を取り出すのと同じ Stash 訪問でマップも取得する（準備開始からマップ起動まで約30秒強→約15〜17秒）。
- 覚醒ボスの HP が 15 秒減らなければ接近、90 秒減らなければ遭遇を諦めて回収・帰還する（The Remembered で 160 グリッド先から雑魚を撃ち続け、5 分×2 回無駄にしていた）。
- Faustus 購入: 1c 未満の安価品を「1個=1c」で注文すると比率警告ダイアログが出て注文が通らない。切り上げた Chaos で買えるだけの数量を注文する（Dawn 1c→3 個）。
- Spell Suppress を NG に追加（ユーザー判断）。
- 性能・砂時計対策:
  - InputTrace はオーバーレイではなく専用スレッドで `Plugins/Temp/AutoExile/InputTrace.log` に出力。
  - Awakening イベントはオーバーレイ出力を廃止し、`events.jsonl` のみに書く（24MB でローテーション）。
  - チェックポイント保存は専用スレッド化（OneDrive ロック時の最大 1.5 秒 Sleep を Tick から排除）。履歴の Visited は削除。
- Stash:
  - 押しっぱなしの修飾キー（Ctrl+右クリックの直後）を解放する。
  - StashieV2 が止まっていれば F3 を最大 2 回再送する。
  - StashieV2 が格納しない装備は Tmp へ移し、Prepare でのループを防ぐ。
- 凍結中の Legion（LegionLeague / MonsterChest*）はクリア対象から除外。
- ボス戦中は Rare/Unique が 8 グリッド以内、または 4 体以上が 12 グリッド以内にいれば、被ダメ前でも先にカイトする。

## 残課題・気づき
1. **死亡率が最大の損失**: 23 マップ中 10 マップで死亡（43%）。
   - 場面は Scout 6、Fight 4、Loot 4。
   - Mod 別の死亡率（母数は少ない）: 床パッチ 2/2、+2 Projectiles 5/8、Crit 系 4/8、extra Phys as Ele 3/6、40% less CDR 3/5、Lunaris 2/3。
   - 一撃死（ES 4700→0 が 1 秒以内）が多く、"hurting" 判定では間に合わない。
2. **Loot 中の死亡**: 遠く（130〜190 グリッド）の安価品を取りに行って死んでいた。10c 基準で減る見込み。
3. **死亡後のポータルが "Dunes (Completed)" 表示になり放棄されるケース**（06:54、ボス未討伐）:
   - 修正前は `unrecognized_portal_set` で停止、修正後は放棄して新しいマップへ進む。
   - ボス未討伐のまま素材を失うので、Completed 判定の条件（`PortalLooksComplete`）を要調査。
4. **Faustus の 1 取引あたり約 9〜17 秒**: 大半はアイテム選択の検索入力。取引間で窓を開いたまま使い回す余地がある。
5. **Chaos 残高が減少傾向**（3107→1825c）:
   - Horned Scarab 136c×5 などの購入に対し、Chisel 類は出品してから売れるまで Chaos 化しない。
   - `listBelowChaos=400` の閾値で出品が始まる。
6. **マーケット購入**: 1 回で 8〜10 枚（7〜12c/枚）買えている。NOT フィルタの入力は 1 ルールあたり約 15 秒と遅いが、初回だけ。
7. **Awakening 覚醒ボスの探索**: マップによっては 2 分以上 Scout が続く（ボス出現位置が不明）。
8. **ログ関連**:
   - `events.jsonl` は 24MB ごとに `events-<UTC>.jsonl` へローテーションされる。
   - AwakeningData フォルダに 536 ファイル（UI ダンプや evidence）が溜まっており、OneDrive 同期の負荷源になりうる。
9. **チェックポイント**: 約 2MB。現在の Run 分と Requests 履歴が大きい可能性がある。
